# Deals Automation

Тестовое задание на PHP и n8n.

Задача проекта — получить список сделок из внешнего API, запросить подробную информацию по каждой сделке и отобразить результат в HTML-таблице.

## Структура проекта

```text
deals-automation/
├── php/
│   └── index.php
├── n8n/
│   └── workflow.json
└── README.md
```

## Как работает проект

PHP-страница выполняет один GET-запрос к n8n Webhook.

Дальше вся работа с внешним API выполняется внутри workflow n8n:

```text
PHP
↓
n8n Webhook
↓
получение списка ID сделок
↓
получение данных по каждому ID
↓
формирование общего JSON-ответа
↓
PHP
↓
HTML-таблица
```

PHP напрямую к внешнему API не обращается.

## Внешний API

Для получения данных используются два метода.

Получение списка ID сделок:

```text
GET /webhook/api/test.task/get.element.list
```

Пример ответа:

```json
{
  "result": {
    "deals": [
      1001,
      1002,
      1003
    ]
  }
}
```

Получение подробной информации по одной сделке:

```text
GET /webhook/api/test.task/get.element?id={id}
```

Для отображения в итоговой таблице используются поля:

```text
id
title
amount
responsible.id
responsible.name
company.id
company.name
```

## n8n workflow

Основная ветка workflow:

```text
Webhook
→ API Configuration
→ Get Deal IDs
→ Split Deal IDs
→ Get Deal Details
→ Build Deals Response
→ Respond to Webhook
```

Отдельно реализована ветка обработки ошибки получения списка ID:

```text
Get Deal IDs
→ Error
→ Build List Error Response
→ Respond to Webhook Error
```

### Webhook

Принимает GET-запрос от PHP:

```text
GET /api/test.task/get.deals
```

### API Configuration

Содержит базовый URL внешнего API и пути к используемым методам:

```text
apiBase
listPath
detailPath
```

### Get Deal IDs

Получает список ID сделок из внешнего API.

### Split Deal IDs

Преобразует массив ID в отдельные элементы для дальнейшей обработки.

### Get Deal Details

Для каждого ID выполняет запрос подробной информации по сделке.

Если запрос по одной из сделок завершается ошибкой, выполнение workflow продолжается, а остальные сделки продолжают обрабатываться.

### Build Deals Response

Собирает успешные результаты и ошибки в один JSON-ответ.

Итоговый формат:

```json
{
  "success": true,
  "partial": false,
  "total": 10,
  "deals": [],
  "errors": []
}
```

Поля ответа:

- `success` — удалось ли выполнить основной сценарий;
- `partial` — были ли ошибки по отдельным сделкам;
- `total` — количество успешно полученных сделок;
- `deals` — массив успешно полученных сделок;
- `errors` — массив ошибок.

## Пример успешного ответа

```json
{
  "success": true,
  "partial": false,
  "total": 10,
  "deals": [
    {
      "id": 1001,
      "title": "Сделка с ООО Ромашка",
      "amount": 1250000,
      "responsible": {
        "id": 12,
        "name": "Иван Петров"
      },
      "company": {
        "id": 78,
        "name": "ООО Ромашка"
      }
    }
  ],
  "errors": []
}
```

## Обработка частичной ошибки

Если данные по одной сделке получить не удалось, остальные сделки продолжают обрабатываться.

Пример:

```json
{
  "success": true,
  "partial": true,
  "total": 9,
  "deals": [
    {
      "id": 1001,
      "title": "Сделка с ООО Ромашка",
      "amount": 1250000,
      "responsible": {
        "id": 12,
        "name": "Иван Петров"
      },
      "company": {
        "id": 78,
        "name": "ООО Ромашка"
      }
    }
  ],
  "errors": [
    {
      "id": 999999,
      "message": "Сделка с ID 999999 не найдена"
    }
  ]
}
```

В этом случае PHP отображает успешно полученные сделки, а ниже выводит предупреждение по ошибочным элементам.

## Обработка ошибки получения списка ID

Если исходный список ID получить не удалось, дальнейшая обработка сделок не выполняется.

Workflow возвращает структурированный ответ:

```json
{
  "success": false,
  "partial": false,
  "total": 0,
  "deals": [],
  "errors": [
    {
      "stage": "get_deal_ids",
      "message": "Failed to get deal IDs from external API"
    }
  ]
}
```

Для этой ситуации используется отдельная ветка `Respond to Webhook Error`.

## PHP

Файл:

```text
php/index.php
```

выполняет один GET-запрос к n8n Webhook.

Полученный JSON преобразуется в PHP-массив, после чего массив `deals` используется для построения таблицы.

PHP не выполняет отдельные запросы к внешнему API по каждому ID.

## Таблица

Для отображения используется Bootstrap 5.

В таблице выводятся:

```text
ID
Название
Сумма
Ответственный
Компания
```

Если часть сделок не удалось получить, успешные сделки всё равно отображаются.

Если получить исходный список сделок не удалось, вместо таблицы выводится сообщение об ошибке.

## Запуск

Для локального запуска необходимо перейти в каталог `php` и запустить встроенный PHP-сервер:

```bash
php -S localhost:8000
```

После этого открыть в браузере:

```text
http://localhost:8000
```

## Проверка

Проверены следующие сценарии:

- успешное получение всех сделок;
- ошибка получения одной сделки без остановки обработки остальных;
- ошибка получения исходного списка ID;
- вывод данных на PHP-странице в виде Bootstrap-таблицы.
