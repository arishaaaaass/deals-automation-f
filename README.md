# Deals Automation

**Тестовое задание по автоматизации получения данных о сделках через n8n и отображению результатов на PHP-странице.**

Demo API:
https://deals-automation.app.n8n.cloud/webhook/api/test.task/get.deals
---

##  О проекте

Проект реализует получение данных о сделках из внешнего API с помощью **n8n** и их отображение на простой **PHP-странице**.

Архитектура приложения:

```text
PHP → n8n → внешний API
```

PHP выполняет **один GET-запрос** к n8n, а всю работу с внешним API выполняет workflow.

##  Как работает проект

Workflow в n8n выполняет несколько последовательных шагов:

1. Принимает GET-запрос через Webhook.
2. Получает список ID всех сделок из внешнего API.
3. Разделяет полученный список на отдельные ID.
4. Для каждого ID получает подробную информацию о сделке.
5. Формирует единый JSON.
6. Возвращает результат PHP-странице.

Схема работы:

```text
Webhook
   ↓
API Configuration
   ↓
Get Deal IDs
   ↓
Split Deal IDs
   ↓
Get Deal Details
   ↓
Build Deals Response
   ↓
Respond to Webhook
```

##  Внешний API

Для получения списка ID сделок используется:

```text
GET /webhook/api/test.task/get.element.list
```

Для получения подробной информации по конкретной сделке:

```text
GET /webhook/api/test.task/get.element?id={id}
```

Базовый адрес API:

```text
https://run.mob-edu.ru
```

##  Обработка ошибок

Workflow настроен таким образом, чтобы ошибка при получении одной сделки **не останавливала обработку остальных сделок**.

Например, если одна сделка не существует, остальные данные всё равно будут возвращены.

Пример частичного результата:

```json
{
  "success": false,
  "total": 9,
  "data": [],
  "errors": [
    {
      "id": 999999,
      "message": "Сделка с ID 999999 не найдена"
    }
  ]
}
```

Таким образом, информация об ошибочных запросах сохраняется отдельно в массиве `errors`.

##  PHP-страница

PHP-страница находится в файле:

```text
php/index.php
```

Она выполняет **один GET-запрос** к n8n и получает уже подготовленные данные.

После этого PHP динамически формирует таблицу.

### Колонки таблицы

| Поле | Описание |
|---|---|
| ID | Идентификатор сделки |
| Название | Название сделки |
| Сумма | Сумма сделки |
| Ответственный | Ответственный сотрудник |
| Компания | Компания клиента |

Для оформления страницы используется **Bootstrap**.

```bash

В браузере открыть:

http://localhost:8000
```

##  Используемые технологии

- **n8n** — автоматизация запросов к API
- **PHP** — получение результата и построение страницы

- **JSON** — обмен данными между n8n и PHP

## ✅ Результат

В результате реализована схема:

```text
PHP
 ↓
n8n Webhook
 ↓
Получение списка ID
 ↓
Получение данных по каждой сделке
 ↓
Обработка возможных ошибок
 ↓
Формирование единого JSON
 ↓
HTML-таблица
```

PHP не обращается напрямую к внешнему API — вся логика получения и обработки данных находится в **n8n**.
